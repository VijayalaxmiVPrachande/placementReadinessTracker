# **App Name**: AssessPro Admin

## Core Features:

- Admin Authentication: Secure login page with userid 'admin' and password '123'.
- Aptitude Test Upload: Upload aptitude tests with questions to Firestore.
- Soft Skills Test Upload: Upload soft skills tests with questions to Firestore.
- User Data View: View user profiles, aptitude scores, coding scores, soft skill scores, and USN from Firestore.
- Progress Tracking: Display user progress based on test scores stored in Firestore.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to inspire trust and stability in the admin interface.
- Background color: Light gray (#F0F2F5), a desaturated variant of the primary, creating a neutral backdrop that won't distract from content.
- Accent color: Vivid orange (#FF9800), an analogous color used for call-to-action buttons and important highlights, to grab attention.
- Headline font: 'Space Grotesk' sans-serif for a modern, tech-forward feel. Body font: 'Inter' sans-serif to maintain excellent readability. 
- Use simple, consistent icons from a library like Material Design Icons to represent tests, users, and settings.
- Implement a clean, sidebar-based layout for easy navigation within the admin dashboard.
- Use subtle animations for page transitions and data loading to improve user experience.
